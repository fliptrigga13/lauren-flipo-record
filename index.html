What this page is

On October 12, 2026, the largest AI lab on Earth announced its frontier agent models with two headline features: Active Memory, an agent that carries what matters to you across conversations, and Active Focus, an agent that checks in before following through on anything important.

This page is not a complaint. It is a receipt book. The same capabilities were designed, coded, and running on one man's local hardware in the spring of 2026, months earlier, and the files are dated. What follows is that record, exactly as the archives hold it.

Three dated proofs

March 5, 2026

Persistent memory

A local memory store for a multi-agent system, persisting across sessions: 336 records in its first three days, growing in the chat record from 83 entries on March 13 to 200 entries and 196 session facts on March 14, with a scored top-150 episodic layer over an 11,302-entry database by April 4.

Evidence: cosmos_memory.json; system chat logs, Mar 13–Apr 4, 2026
March 28, 2026

The cost gate

CHRONOS, a utility and cost gate written in code: no agent cycle fired unless expected value exceeded the failure penalty drawn from its own failure memory. Autonomy, rationed by math, on local hardware.

Evidence: nexus_chronos.py, CostGate class, threshold constant 0.35
April 4, 2026

The approval gate

The system's written operating rules: code execution queues for human approval before it runs, and any confidence score under 0.9 blocks autonomous action outright. A check-in before anything important, half a year before it became a keynote feature.

Evidence: AGENT_CONTEXT.md operating rules, Apr 4, 2026
